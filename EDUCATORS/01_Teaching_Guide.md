# ANTICODE_AGENT — Educator's Teaching Guide

## Course Fit: AI-assisted software engineering, autonomous coding agents, developer tooling

## 3-Week Module: Sovereign Code Generation Agents

### Week 1: The Anatomy of a Code Agent
**Lecture Topics:**
- What distinguishes a code agent from a code autocomplete tool
- The plan-execute-verify loop: how ANTICODE_AGENT structures its reasoning
- Tool use in coding agents: file read/write, shell execution, test runners
- Why sovereign (local) execution matters for enterprise codebases

**Lab Exercise:**
```python
# Install and configure ANTICODE_AGENT with a local Ollama backend
import subprocess
subprocess.run(["ollama", "pull", "codellama:13b"])

# Point the agent at a local model
import anticode_agent as aca
agent = aca.Agent(
    model_backend="ollama",
    model_name="codellama:13b",
    workspace="./sandbox_project"
)
task = "Write a Python function that parses CSV files and returns a list of dicts"
result = agent.run(task)
print(result.code)
```

### Week 2: Implementation — Planning, Execution, and Self-Correction
**Lecture Topics:**
- How the agent decomposes tasks into subtasks
- Execution sandboxing: why agents need isolated environments
- Feedback loops: test failures as corrective signals
- Diff generation and atomic commits

**Lab Exercise:**
```python
# Run a multi-step refactoring task
agent = aca.Agent(model_backend="ollama", model_name="codellama:13b")
plan = agent.plan("Refactor the auth module to use JWT tokens instead of sessions")
for step in plan.steps:
    result = agent.execute(step)
    print(f"Step {step.id}: {result.status}")
    if result.tests_failed:
        fix = agent.self_correct(result)
        print(f"Self-corrected: {fix.patch}")
```

### Week 3: Integration with Anticloud System
**Lecture Topics:**
- AIOSS ledger entries generated by ANTICODE_AGENT
- Connecting to ANTICLOUD_DEPLOYMENT for CI/CD pipelines
- Security model: what the agent is allowed to modify

**Lab Exercise:**
```python
# Emit AIOSS-format audit events
from aioss_format import AIOSSLedger
ledger = AIOSSLedger()
agent = aca.Agent(model_backend="ollama", model_name="codellama:13b",
                  ledger=ledger)
agent.run("Add unit tests for the payment service")
ledger.export("agent_session.aioss.json")
```
